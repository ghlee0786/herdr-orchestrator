# 세션 연속성 · 복구 · 칸 정리

## 원칙
- 이어 하는 일은 **원래 대화 id · cwd · 레인 · 모델 · effort · 권한**으로 되살린다. 새 세션을 겹쳐 만들지 않고, 멈췄던 목표를 새 목표로 복제하지 않는다.
- 살아 있다는 증거가 **아닌** 것: 장부의 active/ready 기록 · 셸 이름(foreground) · `--keep` 으로 되살아난 셸. 칸 아래에 에이전트 프로세스가 실제로 있는지(프로세스 부모 관계) 또는 `hc wait` 종료 알림으로 확인한다.
- 글 보내기 성공은 기동 성공이 아니다.

## 칸 장부
칸 하나 = 한 줄: 이름 · 탭(where) · 머신 · cwd · 대화 id · 모델 · effort · 대기열 파일 · 보존 여부.
대화 id 를 정하는 차례: ① 실행 중 프로세스가 연 세션 파일 → ② 명령줄 `--resume <id>` → ③ 칸 라벨 `original.session`. 셋이 엇갈리면 그 칸은 손대지 않고 총괄에 알린다.

## 원클릭 복구 실행기
1. 잠금을 잡는다(실행기 두 개가 겹쳐 돌지 않게).
2. Core · App 상태를 먼저 백업한다.
3. App · Core 가 뜰 때까지 기다린다(상한 있음).
4. 명부대로 **원래 대화 id 로만** 재개한다. 건너뜀: 이미 도는 칸 · 지운 칸 · 그 대화가 다른 곳에서 돎 · 라벨과 장부가 다름 · 믿지 않는 폴더 · 1시간 안에 실패한 칸.
5. 배치가 비어 있으면 성공으로 치지 않고 멈춘다.
6. `hc wait` 와 프로세스 부모 관계로 확인한 뒤 결과 파일 · 확인 목록을 남긴다.
- 신뢰 · 허락 창은 누르지 않고 총괄에 알린다.
- 되살리는 차례: 총괄 → 창구 → 결정 매니저 → 나머지.

## 자동 되살림(Heal)
- 사용자 세션 예약 작업이 15분마다 칸 장부를 읽고 「셸만 남은 칸」(CLAUDE_EXITED)을 같은 대화 id 로 재개한다. 건너뜀 조건은 실행기와 같다.
- 재개 글은 상황별로 다르다(`templates/resume-prompts.md`):
  - 칸 하나 되살림: 「결과부터 읽고 하던 데서 잇기」.
  - PC 전체 복구 · 재부팅: 「새 입력을 기다리고, 끊긴 명령을 다시 돌리지 않음 — 결과 · 상태부터 보고」.

## Core 재시작 전후 대조
1. 재시작 전 칸 모습을 찍는다(이름 · 상태 · keep · foreground · 라벨).
2. 재시작은 사람 GO 뒤.
3. 재시작 뒤 다시 찍어 사라진 칸 · 바뀐 칸을 센다.
4. 되살림을 마른 실행(dry-run)으로 계획 → 확인 → 적용.
- 감시견은 `hc server status` 의 시작 시각이 바뀌면 `CORE_RESTART` 를 낸다.

## 주소 바뀜 공지
복구 뒤 터미널 주소가 바뀔 수 있다. 옛 주소 → 새 주소 표를 칸 전체에 한 번 알리고, 이후 주소를 쓰기 전에는 늘 `hc get` 으로 이름 · `original.session` 을 대조한다.

## 재부팅 뒤
1. 원인 먼저: OS 이벤트(비정상 종료 · 업데이트 자동 재시작)로 가린다.
2. 총괄마다 상태 보고(`templates/status-report.md`): 원래 업무 · 경위 · 재부팅 뒤 한 일(증거) · 지금 도는 것 · 남은 다음 동작.
3. 모든 칸: 끊긴 뒤 작업을 확인하고 앞 명령을 다시 돌리지 않고 결과부터 읽은 뒤 한 줄 보고.
4. 깨움 예약(Cron) 다시 걸기.

## 에이전트 CLI 판 통일 · 업데이트
- 설치본이 여러 개일 수 있다. 칸별 프로세스 · 세션 파일로 목록을 만들고 한 실행 파일로 같은 id 를 다시 띄운다 → 판 분포 · 중복 0 확인.
- 업데이트 중에는 실행 파일이 바뀌어 기동이 실패한다 → `--version` 이 성공한 뒤 실패한 칸만 다시.

## 칸 닫기
- 대상: 120분 넘게 쉰 칸 · 끝난 감시 · 일회용 셸.
- 제외: 보존 목록 · 입력 중 · 미커밋 레인 · 자식 프로세스가 도는 칸 · 이번 회차에 일을 맡긴 칸 · 기다리는 칸 · 감시 칸.
- 차례: 인계 메모(`templates/handoff.md`, 15줄 안) → 다음 회차에 `hc keys <칸> ctrl+c` 두 번(hc 로 보낸 `/exit` 는 안 먹을 수 있음) → 프로세스가 실제로 끝났나 확인 → 인계 색인 갱신(대화 id · cwd · 시각 · 재개 명령).
- 닫기 전에 그 칸이 띄운 상주 프로그램을 확인한다. 대화는 지우지 않는다. 이름을 바꿀 때도 같은 id 로 재개한다.
