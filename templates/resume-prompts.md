# 재개 글

상황마다 다르다. 공통: 새 일을 시작하지 않는다 · 같은 대화 · 같은 레인 · 멈춘 목표를 새 목표로 복제하지 않는다.

## ① 총괄 — 계정 바꿈 · 칸 하나 되살림
[재개] 하던 일을 같은 대화 · 같은 레인으로 잇는다.
1. 목표 파일 · 규칙(공통 + 갈래) 다시 읽기. 2. 상태는 기억 말고 실제로 확인(`hc ls` · `hc get` · 레인 · 병합 대기 · 판). 3. 남은 일은 지시 장부 '진행' 줄 기준. 4. 칸에 다시 줄 때 규칙 + 업무를 같이. 5. 깨움 예약 다시 걸기. 6. 답은 정해진 답 길로 한 줄.

## ② 작업 칸 — 칸 하나 되살림
[재개] 결과부터 읽고 하던 데서 잇는다. 규칙 · 대기열 다시 읽기 → 레인 · 커밋 · 미커밋 확인 → 끊긴 뒤 작업의 결과 확인(다시 돌리지 않음) → 이어서 → 끝 보고에 지킨 규칙 번호.

## ③ 원격 오케스트레이터
[재개] 이 PC 시험을 같은 대화로 스스로 끝까지. 규칙 · 스킬 다시 읽기 → 칸이 작업 탭 안인지 → 묶음의 끝나지 않은 걸음부터 → 되풀이 예약 다시 걸기 → 결과 · 막힘만 지휘에.

## ④ PC 전체 복구 · 재부팅
[복구] 이 PC 가 다시 켜졌다. 끊긴 명령을 다시 돌리지 말고, 지금 상태와 끊긴 작업의 결과만 확인해 `templates/status-report.md` 꼴로 한 번 보고한 뒤 새 입력을 기다린다. 깨움 예약은 다시 건다.
